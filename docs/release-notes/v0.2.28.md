### 新增 / Added
- **tar 包安装脚本 `install.sh`**：解压后用普通桌面用户运行 `./install.sh`。程序和插件装到 `~/.local`，写入用户级 systemd 服务（已有则保留），
  并检查 FFmpeg（需带 libx264）。缺失时询问后经 sudo 用 apt / pacman 安装（`--yes` 不询问，`--no-ffmpeg` 只检查）；Fedora 需先启用 RPM Fusion，
  openSUSE 需 Packman 源，脚本只打印命令、不替你添加第三方源。.deb 包本来就依赖 `ffmpeg`，不受影响。
- **缺 FFmpeg 时的桌面提示**：宿主在启动时和每次有人连接桌面时检查 FFmpeg。不可用时记 error，弹出「无法传输远程画面」桌面通知并给出安装命令；
  没有通知服务的桌面（如精简 Xfce）改为打开宿主窗口，顶部红字提示。最多每 5 分钟一次；装好后重新连接即可，不用重启服务。
- `install.sh` installs into `~/.local`, writes the systemd user unit and installs FFmpeg with libx264 through apt or pacman when missing.
  The host checks FFmpeg at startup and on every desktop connection and shows a desktop notification (or opens its window) when it is missing.

### 验证范围 / Validation
`install.sh` 在 Debian 13（Xfce）上实测：卸掉 FFmpeg 后 `--yes` 自动装回；CI 在 Ubuntu 22.04 上做同样的测试。通知和窗口红字用测试程序在 Xfce 上实测
（有/无通知服务两种情况）；宿主内的完整流程只有编译与 CI 覆盖。
