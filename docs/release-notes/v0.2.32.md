修复端口映射在 ICE 瞬断恢复后被续房拆掉、信令卡死后长时间假在线，以及查看器 CLI 的指针偏移与滚轮。/ Fixes port-mapping teardown after ICE recovery, stalled signaling, and viewer CLI pointer/wheel input.

### 修复 / Fixed
- **ICE 瞬断恢复后连接被拆（#109，感谢 @sinoyster 的细致分析）**：WebRTC 的 ICE 状态回调读到的是占位 DTLS 对象，ICE `Disconnected → Connected` 恢复后 PeerConnection 停在 `New`，15 分钟续房把仍在使用的端口映射当成空闲，拆房并断开所有映射 TCP 流。现在恢复后会回到 `Connected`。
  After a brief ICE drop the peer state settled on `New` instead of `Connected`, so the idle room renewal tore down live port-mapping streams.
- **信令投递卡住时心跳检测失效（#104，感谢 @RiverOnVenus）**：事件队列阻塞时 Engine.IO 超时不再执行，主机可能带着半关闭的连接“在线”数小时。现在有独立看门狗、发送超时和关闭超时。
  Heartbeat detection keeps running when event delivery stalls; the host reconnects instead of staying half-online.
- **查看器 CLI**：16:10 等非 16:9 主机的指针按内容区域映射，不再内偏（#107，感谢 @liuyanghejerry）；鼠标滚轮/触控板转发为滚动（#108，感谢 @liuyanghejerry）。
  Viewer CLI: pointer mapped to the content rectangle of the padded canvas; mouse wheel forwarded.
