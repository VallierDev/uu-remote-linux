### 新增 / Added
- **运行中切换编码器（#85 第③步，#96，感谢 @ferstar）**：`uuremote-server set-encoder auto|cpu|vaapi|nvenc` 和 `set-codec` 写入设置后会通知正在运行的宿主（`SIGUSR2`），
  已连接的桌面在下一帧边界换用新编码器，不用断开重连；VAAPI 不支持真彩 4:4:4 时自动降为 4:2:0 并通知客户端。只通知完整路径相同的宿主程序，
  避免误杀旧版本宿主；没有通知到宿主时会打印提示（下次连接或重启服务后生效）。编码格式（H.264/H.265）偏好仍在下次连接时生效。
- **X11 单屏选择（#98，实验性）**：设置 `UU_X11_MULTISCREEN=1` 后，主机按 `xrandr --listmonitors` 列出各显示器，控制端可选择其中一块，只采集该区域，
  鼠标绝对坐标加上该屏幕的偏移；默认主显示器，`UU_X11_OUTPUT` 可指定其他屏幕。显示器布局在启动时读取，改动后需重启服务；此模式下「分辨率」改为缩放画面。默认关闭，单屏用户不受影响。
- `set-encoder` / `set-codec` now switch a live desktop stream's encoder via `SIGUSR2` (same binary only) without reconnecting.
  `UU_X11_MULTISCREEN=1` lets the viewer pick one X11 monitor (RandR monitors; capture and absolute input follow the selected monitor).
