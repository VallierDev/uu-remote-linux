X11 下切换分辨率会真正修改桌面分辨率。/ On X11 the viewer's resolution choice now changes the desktop resolution.

### 新增 / Added
- **控制端切换分辨率时真正修改桌面分辨率**，与官方 Windows 被控端一致：以前「其他分辨率」只缩放编码画面，选小分辨率反而让字更小更糊。
  现在 X11 下用 xrandr 切换主显示器模式，列表里没有的分辨率会自动添加；选「原始」或断开连接后恢复原分辨率。
  已用官方 Mac 控制端在 GNOME（X11）上实测切换与恢复。设置 `UU_DESKTOP_RESIZE=0` 可回到只缩放画面的旧行为；Wayland 不变。
- On X11 the resolution choice switches the display mode via xrandr (adding the mode when missing) and restores it for
  "original" or on disconnect, like the official Windows host. `UU_DESKTOP_RESIZE=0` restores encoder scaling.

### 修复 / Fixed
- **连接中桌面分辨率变化后画面中断**：以前会把采集失败当成编码器故障，逐个换编码器后停止推流。现在按新尺寸重新采集，鼠标坐标随之更新。
- A desktop resize during a session no longer stops the stream; capture restarts at the new size and pointer mapping follows.
