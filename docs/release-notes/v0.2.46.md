Linux 复制的文本可直接粘贴到 Windows 控制端。/ Text copied on Linux now pastes in the Windows viewer.

### 修复 / Fixed
- **Linux → Windows 文本剪贴板无法粘贴（#151，感谢 @afwer1231 的定位）**：主机提供 Unicode 文本格式时，格式名改用官方 Windows 端的 `predefined_13`（id 仍为 13）。此前的 `CF_UNICODETEXT` 名字会让 Windows 控制端注册一个同名的自定义格式，文本虽已到达但普通粘贴读不到。Mac 控制端按 id 13 识别，不受影响。
  The host now names its Unicode text offer `predefined_13` (id 13), as official Windows peers do. The previous `CF_UNICODETEXT` name made the Windows viewer register a custom format of that name, so the text arrived but normal paste could not read it. The Mac viewer matches by id 13 and is unaffected.

单元测试与 CI；格式名依据官方 Windows/Mac 程序中的字符串对照（推断）。尚未在 Windows 控制端实机验证。
