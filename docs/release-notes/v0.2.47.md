官方客户端的设备卡片在未连接时也能显示 Linux 主机的壁纸。/ Device cards in official clients now show the Linux host's wallpaper while disconnected.

### 新增 / Added
- **上报系统壁纸（#152/#153，感谢 @ferstar）**：已登录的图形主机按官方 Windows 被控端的流程获取文件令牌、上传当前壁纸并回报地址，每 60 秒检查一次，内容不变不重复上传。支持 GNOME/Cinnamon、KDE（Plasma 5/6，含壁纸包和主题默认壁纸）、Xfce；其他桌面可用 `UU_WALLPAPER=/绝对路径/图片` 指定（PNG/JPEG/WebP）。访客与无桌面模式不上报。
  Signed-in graphical hosts fetch a file token, upload the current wallpaper and report its URL, following the official Windows host. Checks run every 60 seconds; unchanged content is not re-uploaded. Supports GNOME/Cinnamon, KDE (Plasma 5/6, including wallpaper packages and theme defaults) and Xfce; other desktops can set `UU_WALLPAPER=/absolute/path/image`. Guest and headless hosts skip it.

### 隐私 / Privacy
默认会把当前壁纸图片上传到 UU 的文件服务；设置 `UU_WALLPAPER_UPLOAD=0` 可关闭。日志只记录结果和失败阶段。
By default the current wallpaper image is uploaded to UU's file service; set `UU_WALLPAPER_UPLOAD=0` to disable. Logs record only the outcome and failing stage.

### 验证范围 / Validation
单元测试与 CI；贡献者在 KDE 上实机确认官方客户端显示壁纸。GNOME/Cinnamon、Xfce 尚无实机验收；多屏、动态/XML 壁纸不在本次范围。
