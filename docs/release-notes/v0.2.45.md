### 修复 / Fixed
- **控制端本地输入法截获按键（#149、#150，感谢 @xfjm136）**：SDL 远程桌面窗口创建后关闭本地文本输入，按键只按物理键转发，由被控端输入法处理；修复本地与远端都用 Shift 切换中英文时，Shift 等按键被本地输入法吞掉的问题。不修改系统输入法设置，GTK 启动器不受影响。
  The SDL remote desktop window now disables local text input after creation, so keys are forwarded as physical keys and the remote IME handles composition; Shift and similar keys are no longer swallowed by the local IME. System IME settings and the GTK launcher are unchanged.
