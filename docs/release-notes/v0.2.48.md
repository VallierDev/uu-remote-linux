### 新增 / Added
- **连接时自动开启防窥（#161，感谢 @RiverOnVenus）**：设置 `UU_PRIVACY_AUTO=picture`（隐私屏保）或 `screen-off`（关闭显示屏），第一个桌面控制端连上后自动开启；默认关闭。控制端自己的防窥请求优先，不覆盖已保存的偏好；远程协助会话同样适用。仅 KDE Plasma Wayland（portal）。
  Set `UU_PRIVACY_AUTO=picture` or `screen-off` to enable the privacy screen when the first desktop controller connects (off by default). The viewer's own request wins and the saved preference is not overwritten; remote-assistance sessions are covered too. KDE Plasma Wayland (portal) only.
- **Omarchy 壁纸自动发现（#157，感谢 @ferstar）**：Hyprland 下的 Omarchy 自动跟随当前壁纸上报。/ Omarchy on Hyprland reports its current background automatically.

### 修复 / Fixed
- **查看端组合键（#163/#165，感谢 @Zhenqiang-Weng）**：窗口失焦再聚焦后，仍按住的 Shift/Ctrl/Alt/Win（Mac 为 Command）在下一次按键前恢复，不再丢失修饰键。/ The native viewer restores still-held modifiers after a focus change.
- **启动器图标（#158，感谢 @Zhenqiang-Weng）**：改用系统主题符号图标，缺少 emoji 字体时不再显示方框。/ Launcher icons use the system icon theme instead of emoji glyphs.
- **信令连接失败日志（#166）**：记录脱敏后的失败原因（类别或 HTTP 状态码，不含 token 和地址），区分服务端拒绝与网络问题。/ Signaling connection failures now log a sanitized reason (category or HTTP status).
