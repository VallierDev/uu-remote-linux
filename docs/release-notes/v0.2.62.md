修复与改进版：移动端剪贴板双向互通、文件下载稳定性、KDE 锁屏与 portal 恢复修复，可自定义云端 API 地址。/ Fixes and improvements: two-way mobile clipboard, more reliable downloads, KDE lock-screen and portal recovery fixes, and a configurable cloud API base URL.

### 新增 / Added
- **自定义云端 API 地址（#254）**：配置文件 `base_url` 或环境变量 `UU_BASE_URL`；扫码登录会把所用地址写入配置，凭据与地址绑定。/ Configurable cloud API base URL via `base_url` in the config file or `UU_BASE_URL`; QR login stores the address it used so credentials stay bound to it.

### 修复 / Fixed
- **移动端剪贴板（#250）**：随 rich 列表一并推送文本，早到的文本暂存后回灌，手机与 Linux 之间文本可双向复制。/ Text is pushed alongside the rich list and early text is held and replayed, so text copies both ways between phone and Linux.
- **文件下载（#249）**：下载块按块号顺序发送、整块读满防短读，回执乱序不再堵塞窗口。/ Download chunks go out in order and are read in full; out-of-order acks no longer stall the window.
- **KDE 锁屏（#251）**：解锁后清理残留锁屏进程，避免再次锁屏变成透明锁屏。/ Leftover lock-screen processes are cleaned up after unlock on KDE, preventing a transparent lock screen next time.
- **Linux 控制端（#252）**：远程桌面窗口不再让 X11 合成器停掉整个桌面的特效。/ The viewer window no longer makes the X11 compositor disable desktop effects.
- **portal 恢复（#221、#255）**：桌面会话期间持有空闲抑制，避免空闲锁屏掐断会话；恢复锁等待限时 15 秒并记录锁状态与重开。/ Idle inhibition is held during desktop sessions; the portal recovery-lock wait is bounded to 15 s with lock and reopen logging.
- **doctor**：输出管道关闭时安静退出。/ `doctor` exits quietly when its stdout pipe closes.
