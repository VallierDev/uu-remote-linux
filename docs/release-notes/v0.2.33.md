修复 Wayland 锁屏或熄屏后，由工具连接（端口映射）升级的桌面视频结束后无法再次打开。/ Fixes a promoted tool connection whose desktop video could not be reopened after the screen locked or blanked.

### 修复 / Fixed
- **锁屏/熄屏后桌面无法重新打开（#114，感谢 @sinoyster 的完整报告）**：通过 capture_desktop 升级为桌面的工具连接上，若 Wayland 采集因锁屏或 DPMS 关闭而结束，再次 capture_desktop 不会重建视频，查看器只剩黑屏。现在会重新请求桌面并在原连接上重启视频，保留原输入租约。
  On a tool connection promoted with capture_desktop, a desktop stream that ended (e.g. Wayland capture failing on lock/DPMS) is now restarted on the next capture_desktop, keeping the original input lease.

### 验证范围 / Validation
单元测试与 CI；#114 的锁屏场景尚未实机复现，欢迎反馈。
