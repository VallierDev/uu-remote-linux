修复与控制端改进版：麦克风误报、剪贴板空 offer、下载应答匹配修复；Linux 控制端自然滚动、快捷键捕获记忆与菜单字号。/ Fixes and viewer improvements: microphone false alarm, empty clipboard offer and download-reply matching fixes; Linux viewer natural scrolling, remembered shortcut grab and readable menus.

### 新增 / Added
- **控制端跟随本机自然滚动（#238）**：控制中心 → 外设 → 跟随本机自然滚动，触摸板方向与本机一致，选择记在 `viewer.json` 的 `follow_natural_scroll`（默认关）。/ Viewer option to follow local natural scrolling for touchpads, saved as `follow_natural_scroll` (off by default).
- **记住「发送系统快捷键」并支持 Ctrl+Alt+K 切换（#234、#235）**：控制端记住键盘捕获设置，Ctrl+Alt+K 一键开关。/ The viewer remembers the keyboard-grab setting; Ctrl+Alt+K toggles it.
- **记住防窥模式（#224）**：设置 `UU_PRIVACY_REMEMBER=1` 后记住控制端上次的防窥模式，默认关闭。/ With `UU_PRIVACY_REMEMBER=1`, the last privacy-mode choice is remembered (off by default).

### 修复 / Fixed
- **麦克风误报（#225）**：未开启麦克风时不再对音频探测返回错误，查看端不再提示麦克风故障。/ Audio probes no longer return an error when the microphone is not enabled, so the viewer stops reporting a microphone fault.
- **剪贴板（#242）**：不再向查看端推送零长度文本 offer。/ No longer pushes zero-length text offers to the viewer.
- **文件下载（#243）**：下载应答不再因 file_index 基准不一致而匹配不上。/ Download replies now match despite a differing file_index base.
- **控制端菜单字号（#239）**：控制中心文字过小的问题已修复。/ Control-center text is readable again.
