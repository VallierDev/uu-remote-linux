GNOME 多显示器与精确触控、niri 适配、控制端控制中心与中英文界面，以及登录设备注册修复。/ GNOME multi-monitor and precise touch, niri support, a viewer control center with Chinese/English UI, and a login device-registration fix.

### 新增 / Added
- **GNOME（Wayland / Portal）多显示器切换（#128，感谢 @spixyy7）**：逐块显示器公布并各自保存 Portal 授权，首次在主机上授权一次，之后静默恢复；最后一个控制端断开后立即停止屏幕共享。
  GNOME Portal: per-monitor sources with per-monitor saved grants (asked once, restored silently); screen sharing stops when the last viewer leaves.
- **niri 支持（#71，感谢 @WALKERKILLER）**：`UU_WAYLAND_MULTISCREEN=1` 下的显示器枚举与切换、旋转输出的正向采集与指针映射、手机端中文输入。其他合成器行为不变。
  niri: output enumeration/switching, upright capture and pointer mapping for rotated outputs, and mobile text input; other compositors unchanged.
- **原生控制端（#129，感谢 @spixyy7）**：按被控端原始分辨率解码、中英文界面（`UU_LANG` 或设置）、控制中心（`Ctrl+Alt+M`）、网络状态面板（`Ctrl+Alt+G`，显示实测 RTT）、连接加载画面。控制端登录不会开启本机被控服务（默认关闭）。
  Native viewer: native-resolution decode, Chinese/English UI, control center, network panel with measured RTT, connection screen. Viewer login does not enable the local host service (off by default).

### 修复 / Fixed
- **GNOME 触控偏移（#128）**：绝对移动与点击改走当前 Portal 流，不再映射到整个多屏桌面。/ Absolute pointer goes through the current Portal stream.
- **账号下出现永远离线的“幽灵”设备（#127，感谢 @spixyy7）**：主机与控制端同时登录时，设备注册在配置文件锁下串行进行并复用已注册的设备。/ Device registration is serialized under a config lock.
- **控制端**：控制中心卡顿与随后的花屏、Wayland 下关闭文件传输窗口崩溃（#129）。/ Viewer menu stalls and resulting corruption; crash closing the file-transfer window on Wayland.
- **TURN over TCP/TLS 经检查型代理**：代理返回 HTTP 时给出明确错误（代理在检查 TLS 内容，TURN 无法通过），不再报含糊的解析错误。/ A clear error when an inspecting proxy answers with HTTP inside the relay stream.
