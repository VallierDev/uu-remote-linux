修复 KDE 托盘图标显示为未知图标；显示器接在 NVIDIA 卡上时默认不再让 NVENC 直接编码 BGRA。/ Fixes the KDE tray icon; NVENC skips direct BGRA input when NVIDIA drives the display.

### 修复 / Fixed
- **KDE 托盘显示成未知（空白页）图标**（#87，v0.2.25 引入）：单色托盘图标改名为 `uuremote-tray-symbolic`，写到 `~/.local/share/icons/hicolor`，
  各家面板的默认图标查找都能找到，仍会随深色/浅色面板着色。已在 Plasma 6.7 / KF6 上用 KIconLoader 按 Plasma 的查找方式验证，Plasma 6.8 面板待报告者确认。
  v0.2.25 留下的 `~/.cache/uu-remote-linux/icons` 不再使用，可以删除。
- **同一张 NVIDIA 卡负责显示时编码变慢**（#16）：显示、采集、编码都在同一张 NVIDIA 卡上时，NVENC 直接编码 BGRA 反而比 CPU 转换慢
  （RTX 5070 4K：探针 82.6 vs 98 fps）。现在只要有显示器接在 NVIDIA 卡上就改用 CPU 转换；核显接显示器的机器不变。`UU_NVENC_RGB=1` 强制直接编码，`=0` 强制 CPU 转换。
- The tray icon is installed as `uuremote-tray-symbolic` in the user hicolor theme, so KDE's default lookup finds it
  (v0.2.25 showed the unknown icon on Plasma 6.8). NVENC no longer takes packed BGRA when a connected monitor hangs off
  an NVIDIA card (slower when the desktop is composited on the encoding GPU); `UU_NVENC_RGB=1` forces it.
