### 修复 / Fixed
- **深色模式下托盘图标看不清**（#87）：托盘改用内置单色符号图标，GNOME（AppIndicator 扩展）和 KDE 会按面板主题自动着色，
  tarball 安装也不用另装图标。旧版 AppIndicator 库或缓存目录不可写时沿用原图标。目前只经过 CI 编译，尚未在 KDE / GNOME 面板上实机确认。
- The tray uses a built-in monochrome symbolic icon (written to the user cache and offered as the indicator's icon theme
  path) that GNOME's AppIndicator extension and KDE recolor for the panel theme. Built in CI; not yet checked on a real panel.
