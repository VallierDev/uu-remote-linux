### 修复 / Fixed
- **网络唤醒助手注册（#209）**：注册唤醒助手时补发 `inner_ip`，云端不再以 422 拒绝，`UU_WOL_HELPER=1` 的主机可以接收唤醒推送并发送魔术包。/ The wake helper registration now sends `inner_ip`, so the cloud accepts it and forwards wake-on-LAN pushes.
- **锁屏监测（#217、#218）**：改为通过 D-Bus 订阅 logind `LockedHint`，不再每秒启动 `loginctl`，减少进程轮询与审计日志噪声；无图形会话时保持订阅、不阻塞启动。/ Lock state is now watched via logind D-Bus `LockedHint` instead of spawning `loginctl` every second.
- **HUD 中文显示（#219）**：HUD 字体选择优先含汉字的字体，修复部分系统（如 Omarchy）HUD 中文显示为方框。/ The HUD prefers a CJK-capable font, fixing tofu boxes on some systems.
