性能优化版：降低视频推流与输入通道的拷贝和解析开销，功能行为不变。/ Performance release: less copying and parsing on the video and input paths; no behavior change.

### 优化 / Improved
- **编码帧零拷贝（#184）**：编码完成帧改用共享缓冲，去掉每帧码流深拷贝。/ Encoded frames use shared buffers, removing a per-frame bitstream deep copy.
- **H.265 关键帧检测与 RTP 分包（#180、#182）**：IRAP 检测改为单趟流式扫描，HEVC RTP 分包改为零拷贝子切片。/ Single-pass streaming IRAP scan; zero-copy sub-slices for HEVC RTP packetization.
- **数据通道解析（#180、#191）**：数据通道包单次解码、CONTROL 通道 JSON 单次解析。/ Single-pass data-channel decoding and single JSON parse on the CONTROL channel.
- **X11 终端检测缓存（#182）**：100ms 缓存，减少高频查询。/ 100 ms cache for X11 terminal detection.
- **文字输入不阻塞（#189）**：文字输入移到阻塞线程池执行，保持先后顺序。/ Text input runs on the blocking pool while preserving order.
