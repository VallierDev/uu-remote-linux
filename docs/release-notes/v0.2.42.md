### 修复 / Fixed
- **niri 主控端与官方 Windows 被控端的双向文本剪贴板（#139、#138，感谢 @tingfeng347）**：niri + Wayland 下检测到 `wl-paste`/`wl-copy` 时改用 wl-clipboard，同步不再依赖窗口焦点；缺少时回退 SDL，其他桌面不变。
  niri viewer: two-way text clipboard with official Windows hosts now uses wl-clipboard when available, falling back to SDL.
- **控制端高帧率（如 144 FPS）下压缩帧队列溢出、反复请求关键帧（#143，感谢 @azuredreamblu-design）**：每轮最多解码 8 个单元（4 ms 软预算），只呈现最新画面，队列 3→8。
  Viewer: compressed frames are decoded in bounded batches so sustained 144 FPS no longer overflows the queue.
- **`inproc-av` 在 GNU ld `--as-needed` 下链接失败（#105，感谢 @ferstar）**：依赖库改到静态引擎库之后链接（仅影响源码构建）。
  Source builds: `inproc-av` link order fixed for `--as-needed`.

### 新增 / Added
- **控制端可选原生手柄与震动（连官方 Windows 被控端，#142，感谢 @azuredreamblu-design）**：`UU_VIEWER_NATIVE_GAMEPAD=1` 启用转发，`UU_VIEWER_NATIVE_RUMBLE=0` 单独关闭震动；默认关闭。
  Viewer: opt-in controller forwarding and rumble for Windows hosts (`UU_VIEWER_NATIVE_GAMEPAD=1`).
- **GTK 界面统一扁平样式，新增 跟随系统 / 浅色 / 深色 外观选项（#144，感谢 @xfjm136）**。
  GTK windows: refreshed styling with System / Light / Dark appearance.
- **源码构建 `wayland,portal,inproc-av` + 显式 VAAPI：Portal DMA-BUF 零拷贝编码、进程内 Opus 音频、锁屏下控制经 uinput（#145，感谢 @ferstar）**；失败时回退原 FFmpeg 管线。预编译包不含该特性。
  Source builds with `wayland,portal,inproc-av`: zero-copy VAAPI from Portal DMA-BUF, in-process Opus audio and lock-screen input via uinput. Not in prebuilt packages.
