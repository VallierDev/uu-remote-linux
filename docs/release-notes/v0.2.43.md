KDE Wayland 被控端新增实验性防窥模式。/ Experimental privacy screen for KDE Wayland hosts.

### 新增 / Added
- **KDE Wayland 被控端防窥模式（隐私 / 关屏，#146，感谢 @ferstar，对应 #140）**：控制端开启防窥后，采集与输入切到 KWin 虚拟输出，物理屏关闭或以壁纸遮挡，本地键鼠暂停；主机进程以任何方式退出都会恢复屏幕和输入。需要 `kscreen-doctor` 与 uinput 权限。
  KDE Wayland hosts: privacy screen (privacy / screen-off) switches capture and input to a KWin virtual output and blanks or covers the physical display; local input is paused and restored on any host exit. Requires `kscreen-doctor` and uinput access.
- 已知限制：Mac 控制端的防窥菜单切换后仍显示“不启用”，实际模式正确；X11 与其他 Wayland 桌面暂不支持。
  Known limitation: the Mac viewer menu still shows "off" after switching; X11 and other Wayland desktops are not supported yet.

### 验证范围 / Validation
单元测试与 CI。防窥模式由贡献者在 KDE Wayland 实机验证；维护者尚未用官方客户端复测。
