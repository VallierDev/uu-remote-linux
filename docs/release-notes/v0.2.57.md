功能与修复版：可选控制端麦克风输入、文件传输空路径防护。/ Feature and fix release: opt-in controller microphone, file-transfer empty-path guard.

### 新增 / Added
- **控制端麦克风输入（实验性，默认关闭，#207）**：设置 `UU_MICROPHONE=1` 后，主机通过已认证的桌面 WebRTC 连接接收控制端 Opus 音轨，并提供独立虚拟麦克风 **UU-远程麦克风**（`uu-remote-microphone`），不修改系统默认输入输出。需要 PipeWire-pulse 或 PulseAudio 13+、`libopus.so.0`、`libpulse.so.0` 与 `pactl`；详见 `docs/remote-microphone.md`。/ With `UU_MICROPHONE=1` the host receives the viewer's Opus track over the authenticated desktop WebRTC connection and exposes a dedicated virtual microphone, leaving system defaults untouched. See `docs/remote-microphone.md`.

### 修复 / Fixed
- **文件传输空路径（#208）**：不带路径的 `send_request` 现在返回协议错误，不再从根目录遍历。/ A `send_request` without a path now returns a protocol error instead of walking `/`.

感谢 @JuckZ 的贡献。/ Thanks to @JuckZ.

### 验证范围 / Validation
单元测试与 CI；维护方未做麦克风实机验收。Windows 4.44.1 新下载流程与端口映射（#208）仍未支持。
