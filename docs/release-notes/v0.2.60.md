功能版：上报版本 4.45.0.4318、GNOME 关屏防窥、发送端自适应码率、中键修复。/ Feature release: client version 4.45.0.4318, GNOME screen-off privacy, send-side bitrate response, middle-button fix.

### 新增 / Added
- **上报版本（#195、#228、#237）**：默认上报 `4.45.0.4318`（官方 Windows 公开版本），控制端「被控端版本过低」提示可选择继续远控；可用 `UU_CLIENT_VERSION` / `UU_VERSION_CODE` 或 config.json 的 `client_version` / `version_code` 覆盖（自行设置更高版本号的风险自负）。/ Reports `4.45.0.4318` by default; override with `UU_CLIENT_VERSION` / `UU_VERSION_CODE` or `client_version` / `version_code` in config.json.
- **GNOME 关屏防窥（#222）**：GNOME Wayland 通过 Mutter DisplayConfig 关屏，本地输入点亮后自动重新关屏。/ GNOME Wayland screen-off privacy via Mutter DisplayConfig, re-blanked after local input wakes it.
- **发送端自适应码率（#220）**：按 RTCP 丢包/RTT 降低编码码率，避免中继链路上 NACK 风暴冻住画面。/ The encoder bitrate follows RTCP loss/RTT so relay paths no longer freeze in NACK storms.

### 修复 / Fixed
- **中键（#232）**：官方控制端的中键（MK_MBUTTON=16）此前被丢弃，现已映射；Linux 控制端中键改发 16。/ The official viewer's middle button (16) is now mapped; the Linux viewer sends 16.

感谢 @ferstar、@hsxian、@alex3236 的贡献。/ Thanks to @ferstar, @hsxian and @alex3236.
