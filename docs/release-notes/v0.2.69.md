### 修复 / Fixed
- **锁屏残留 Mod4 导致手机文字输入挂起（#268，PR #269，感谢 @sean2077）**：KWin 锁屏期间 XWayland 收不到按键，锁屏前按下的 Super 会保持按下状态；此前这会让 uinput 文字方案被拒绝，回退到 `wl-copy` 剪贴板粘贴，而锁屏中的 KDE 拒绝剪贴板客户端，`wl-copy` 永久等待并占住输入锁，之后所有输入都被阻塞。现在 Mod4 不再阻止 uinput 方案；`wl-copy` 限时 1 秒，超时即结束；锁屏时只跳过剪贴板回退，Portal keysym 输入照常。/ While KWin holds the lock screen, XWayland misses key releases, so a Super pressed before locking stays down. That rejected the uinput text plan and fell back to a `wl-copy` paste, which a locked KDE refuses; `wl-copy` waited forever holding the input lock and blocked all later input. Mod4 no longer rejects the uinput plan, `wl-copy` gets a one-second deadline, and only the clipboard fallback is skipped while locked (Portal keysyms still type).
