Hyprland 等 wlroots 合成器上，手机查看端输入法打出的中文/符号文字可正常上屏。/ Phone IME text (Chinese and symbols) from mobile viewers now types correctly on Hyprland and other wlroots compositors.

### 修复 / Fixed
- **wlroots 手机输入法文字（#176，感谢 @Onekki）**：所有 wlroots 合成器统一用独立的虚拟文字键盘，每批文字重新 attach 键位表，ASCII 也按 Unicode keysym 发送；Wayland 下先走 keysym、失败再回退 uinput；输入前释放按键后同步原设备的修饰键状态，避免 Ctrl/Shift 残留。/ All wlroots compositors use a dedicated virtual text keyboard, re-attaching the keymap per batch and sending ASCII as Unicode keysyms; Wayland tries keysyms before falling back to uinput, and modifier state is re-synced to the original device so Ctrl/Shift do not stick.

### 验证范围 / Validation
单元测试与 CI；贡献者在 Hyprland 0.56.2 + fcitx5 实机验证。niri 等其他 wlroots 合成器未实测。
