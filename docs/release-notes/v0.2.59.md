### 修复 / Fixed
- **KDE 锁屏冷连接（#227、#229）**：KDE Plasma（KWin）锁屏后 Portal 采集仍可用，主机默认在锁屏时也打开采集，冷连接直接看到真实锁屏界面并可用远程键盘输入密码，不再停在「正在传输画面」；`UU_LOCKED_CAPTURE=0` 关闭，`UU_LOCKED_CAPTURE=1` 在无法识别桌面时强制开启。GNOME 行为不变。/ On KDE Plasma the host now keeps Portal capture open while locked, so a cold connection shows the real lock screen; `UU_LOCKED_CAPTURE=0` disables it. GNOME is unchanged.
- **源码构建（#226）**：适配 Cargo 新的 build-dir 布局，引擎插件复制到 profile 目录。/ Engine plugins are copied to the profile directory under Cargo's newer build-dir layout.
