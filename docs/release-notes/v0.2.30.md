先开端口映射再打开桌面时不再黑屏；VAAPI 低码率档能压到更低码率。/ Opening the desktop after a port mapping no longer shows a black screen; VAAPI low-bitrate presets go lower.

### 修复 / Fixed
- **端口映射后打开桌面黑屏（#99）**：已有端口映射连接时，Mac 控制端打开桌面不会新建连接，而是在原连接上发送 `capture_desktop`。
  宿主现在会把这条连接转为桌面：画面、光标、剪贴板和会话计数都会启动，剪贴板能力也会重新通告。之后再打开新的桌面时，旧连接只停掉桌面，
  端口映射照常可用。若此前 X11 分辨率有变化，会按新尺寸重建采集。限制：Wayland Portal 后端暂不支持这种方式；这条连接上没有声音。
- **VAAPI 低档码率（#33，#102，感谢 @ferstar）**：in-process VAAPI 编码的最大 QP 从 44 放宽到 51，复杂画面下低档可降到硬件能达到的最低码率；中高档不受影响。
- A viewer that opens the desktop on an existing port-mapping connection (`capture_desktop`) now gets video, cursor, clipboard and session handling on that connection;
  a later desktop stops it without closing the port mappings. In-process VAAPI `max_qp` raised from 44 to 51.
