### 新增 / Added
- **拥塞时帧率自适应（#260，默认关闭）**：`UU_VIDEO_FPS_ADAPT=1` 时，码率已降到下限而链路仍拥塞，编码帧率按阶梯逐级下降（最低 5 fps），链路安静一个探测窗（60 s）后逐级回升；控制端显示的帧率不变。/ With `UU_VIDEO_FPS_ADAPT=1`, once the bitrate cap sits on the floor and the path is still congested, the encoder walks a frame ladder down to 5 fps and climbs back after a quiet 60 s probe window; the viewer keeps showing its nominal rate.
- **`~/.config/uuremote/env.conf`（#261）**：每行一条 `UU_*=值`，启动时读取，重装 systemd unit 后调优项不丢；真实环境变量优先，账号凭据与 `UU_CONFIG` 会被拒绝，日志只记行号和设置名。/ One `UU_*=value` per line, read at startup so tuning survives a unit reinstall; the real environment wins, credentials and `UU_CONFIG` are refused, and logs name only line numbers and keys.
- **剪贴板协商诊断（#211）**：剪贴板 RPC（field 21/22）日志改为结构摘要：嵌套字段号、状态码/请求号等整数与字节长度，不记录任何内容，用于定位 Mac 控制端文本剪贴板协商停在哪一步。/ Clipboard RPC (field 21/22) logs now show a structure summary — nested field numbers, integer status/id values and byte lengths, never content — to locate where Mac viewer text-clipboard negotiation stops.
