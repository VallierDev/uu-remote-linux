修复版：Mac 控制端连接 GNOME Wayland Portal 主机时首次连接即可双向同步剪贴板。/ Fix release: Mac viewers connecting to GNOME Wayland Portal hosts get two-way clipboard on the first connection.

### 修复 / Fixed
- **Mac ↔ Portal 剪贴板（#264，Fixes #211）**：Mac 控制端只按第一次 Echo 回复锁定剪贴板能力。主机现在在未锁屏时推迟首个 Echo（不阻塞其他控制消息），直到 Portal 剪贴板桥就绪（等待授权时最多 60 秒，Portal 就绪后最多 8 秒）；锁屏时立即回复以免延迟自动解锁，仅在已确认过 Portal 剪贴板授权时声明剪贴板能力；未知状态、Portal 不可用或超时一律不声明剪贴板。仅作用于 Mac 控制端 + Portal 会话。/ The Mac viewer latches clipboard capability from the first Echo reply only. When unlocked, the host now holds the first Echo (without blocking other control messages) until the Portal clipboard bridge is ready (up to 60 s while awaiting consent, 8 s once Portal is ready); when locked it replies at once so auto-unlock is not delayed, advertising clipboard only if a Portal clipboard grant was already confirmed; unknown state, unavailable Portal or timeout fail closed. Scoped to Mac viewers on Portal sessions.
