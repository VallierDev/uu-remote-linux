新平台与打包版：新增龙芯 LoongArch64 预编译包，以及 Nix flake / NixOS 模块。/ Platform and packaging release: LoongArch64 prebuilt packages and a Nix flake / NixOS module.

### 新增 / Added
- **龙芯 LoongArch64（#257）**：发版后在 QEMU 中构建 `uu-remote-linux_0.2.63_loong64.deb` 与 `uu-remote-linux-v0.2.63-loongarch64-linux.tar.gz`（Release 完成后数小时内追加）；为此 vendored rcgen 升级到 ring 0.17、nix 补 loongarch64 ioctl 表。/ LoongArch64 `.deb` and tarball built under QEMU after each release (attached a few hours after the release); vendored rcgen moves to ring 0.17 and nix gains the loongarch64 ioctl table.
- **Nix flake 与 NixOS 模块（#258）**：提供 package、NixOS 模块与独立 Nix 安装说明，附 NixOS VM 测试。/ A Nix flake with a package, a NixOS module, standalone Nix install docs and a NixOS VM test.

### 变更 / Changed
- **打包资源整理（#258）**：systemd、udev、desktop 文件统一到 `packaging/common`，Docker 文件移到 `packaging/docker`；deb/tar.gz 内容不变。/ systemd, udev and desktop assets now live in `packaging/common` and Docker files in `packaging/docker`; package contents are unchanged.
