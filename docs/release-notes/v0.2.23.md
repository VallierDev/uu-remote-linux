长时间连接后画面冻结的修复。/ Fixes video freezing after long sessions.

### 修复 / Fixed
- **控制端切到后台再恢复后画面冻结、延迟显示 0**（#83，感谢 @AYssu 定位并提供补丁）：RTP 序号每 65536 包回绕一次；
  回绕后如果控制端补要（NACK）回绕前的旧包，webrtc-srtp 0.12.0 会把加密状态退回旧值，之后的新包都用错误的回绕计数加密，
  控制端全部认证失败，画面停住且不再恢复。现按 RFC 3711 附录 A 估算回绕计数，重传不再让状态倒退。加密算法和报文格式不变。
  回归测试在原库上失败、修复后通过（AES-CM/HMAC 与 AES-GCM）；报告者在 Windows 控制端实测后台放置恢复正常，跨过两次回绕。
- SRTP rollover counter no longer rewinds when a pre-wrap packet is retransmitted after the wrap (frozen video, #83).
