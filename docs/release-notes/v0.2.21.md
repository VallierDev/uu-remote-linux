### 修复 / Fixed
- **只缺 wlr-virtual-pointer 或虚拟键盘受限的合成器整个桌面不可用**（#72、#73，感谢 @clionertr）：Denial 等合成器不提供
  `zwlr_virtual_pointer_manager_v1`，或只把虚拟键盘给它自己的输入法。现在这两个协议都是可选的：画面采集照常启动，
  缺指针时绝对移动改走 uinput（需能访问 `/dev/uinput`，见 README）；`UU_WAYLAND_NO_VIRTUAL_KEYBOARD=1` 可跳过虚拟键盘。
  只有「完全没有虚拟指针」才回退 uinput；坐标超出当前采集输出等其他失败照旧返回，不会把指针移到别的屏幕（#78）。
  CI 构建与测试通过，**未在 Denial 上实机验证**；Hyprland 等已有虚拟指针的合成器行为不变。
- Virtual pointer and keyboard are optional on Wayland; capture still starts and pointer motion falls back to uinput only when
  the compositor has no wlr-virtual-pointer. Not tested on Denial.

### 文档 / Docs
- README 的用户 systemd 单元与 deb 包一致：不再写死 `DISPLAY=:0`，随 `graphical-session.target` 启动；无头模式、虚拟桌面和
  Xfce/i3 等不启动该 target 的桌面改用 `WantedBy=default.target`（#69，感谢 @ferstar）。
