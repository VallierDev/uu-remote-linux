### 修复 / Fixed
- **Windows 文本剪贴板（#200，修 #151）**：主机提供 Windows Unicode 文本（预定义格式 id 13）时不再附带格式名字段，避免 Windows 控制端把它注册成自定义格式、导致无法粘贴。Mac 格式名、UTF-16LE 编码、CRLF 与结尾 NUL 不变。/ The host now offers predefined Windows Unicode text (id 13) without a format name, so the Windows viewer no longer registers it as a custom format and standard paste works. Mac format names, UTF-16LE encoding, CRLF and the terminating NUL are unchanged.

感谢 @max2787 的贡献。/ Thanks to @max2787.
