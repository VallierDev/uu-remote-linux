NVENC 新增可选 VBV 缓冲开关，缓解高分辨率下关键帧按 GOP 周期闪烁。/ Opt-in NVENC VBV buffer for high-resolution keyframe pulsing.

### 新增 / Added
- **`UU_NVENC_BUFFER_MS`（#103，感谢 @zhl-HFUT 的分析）**：NVENC 的 VBV 缓冲（10–1000 ms，缓冲 = 码率上限 × 毫秒 / 1000），FFmpeg 进程管线和进程内引擎都生效。
  默认缓冲（100–500 kbit）在 1440p 等高分辨率下会把关键帧压糊，画面按 GOP 周期“糊一下再变清”；遇到时可设 `UU_NVENC_BUFFER_MS=1000`。默认行为不变。
- New `UU_NVENC_BUFFER_MS` (10–1000 ms of the bitrate cap) for NVENC, applied to both the FFmpeg pipeline and the in-process engine. Default unchanged.
