功能与修复版：防窥模式、嵌入式光标、NVENC 关键帧画质。/ Feature and fix release: privacy mode, embedded cursor, NVENC keyframe quality.

### 新增 / Added
- **嵌入式光标跟随控制端鼠标模式（#203）**：Portal 采集在控制端使用相对移动（"使用被控端鼠标"、Mac 触控板模式）时请求 `cursor_mode=embedded`，让游戏光标出现在画面中；绝对移动时保持隐藏，只显示一个指针。/ Portal capture asks for an embedded cursor while the viewer sends relative motion, so the game's cursor shows in the picture; absolute motion keeps it hidden.

### 修复 / Fixed
- **Windows 控制端防窥请求（#202）**：Windows 控制端（平台 1）以 `enable=0` 加 `privacy_type` 表达意图，主机现在按类型（2 画面、3 熄屏）开启防窥，不再误判为关闭。/ The host now honours the Windows viewer's `enable=0` + `privacy_type` encoding instead of treating it as "off".
- **防窥画面模式下的新窗口（#201）**：KWin 防窥模式中后出现的窗口和桌宠会被移到虚拟输出，不再落在被遮盖的物理屏上而看不见。/ Windows that appear later in KWin picture mode are moved to the virtual output instead of the covered physical screen.
- **NVENC 关键帧模糊（#205，修 #103）**：NVENC 的 VBV 缓冲默认按 libx264 规则取码率并限制在 500–8000 kbit，关键帧不再糊；VAAPI 不变，`UU_NVENC_BUFFER_MS` 仍可覆盖。/ The NVENC VBV buffer now follows the libx264 rule (bitrate, clamped to 500–8000 kbit) so keyframes stop blurring; VAAPI is unchanged and `UU_NVENC_BUFFER_MS` still overrides.
